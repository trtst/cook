# 功能执行单：菜谱创建、展示与后台用户菜谱域

## 目标

- 本功能要跑通的最小业务闭环：
  - 小程序用户新建菜谱 -> 存草稿 -> 继续编辑 -> 发布到“我的” -> 在“我的”列表和详情展示
  - 小程序用户浏览灵感列表与详情 -> 收藏到合集 -> 在合集列表和合集详情展示
  - 后台管理员从用户视角查看该用户的菜谱域概览、已发布、草稿、合集和合集内容
- 对应 V1 范围：
  - 个人菜谱、草稿、灵感只读、收藏到合集、后台基础治理查看

## 本轮范围

- 小程序端：
  - 结构化菜谱录入
  - 草稿保存、继续编辑、发布、删除
  - 我的列表、我的详情、再编辑
  - 灵感列表、灵感详情
  - 收藏到合集
  - 合集列表、合集详情
- 后端 API：
  - 菜谱、草稿、灵感只读、收藏/合集最小接口
  - 后台用户菜谱域和合集域查询接口
- 后台管理：
  - 用户列表新增“查看菜谱域”入口
  - 独立“用户菜谱域详情页”
  - 已发布 / 草稿 / 合集 3 个 tab
  - 合集内容页
- 共享契约：
  - `docs/api-contract.md`
  - API DTO / OpenAPI
  - `apps/client` / `apps/admin` 本地 API 类型

## 本轮不做

- 从合集升级为“我的”
- 再次导入原版
- 推荐到灵感审核
- 点赞、收藏统计和灵感排序闭环
- 图片上传、封面写入、步骤图写入
- 分享、饭局、计划联动改造

### 业务流程

- 用户目标：
  - 记录自己的菜谱并持续编辑
  - 把灵感菜谱收藏进合集统一整理
  - 管理员按用户视角核对菜谱域和合集域事实
- 触发条件：
  - 登录用户进入菜谱创建或管理流程
  - 登录用户从灵感详情执行收藏
  - 管理员从用户列表进入用户菜谱域详情
- 主成功路径：
  - 新建菜谱 -> 保存草稿 -> 草稿箱继续编辑 -> 发布 -> 我的列表 -> 我的详情 -> 再编辑 -> 再发布
  - 灵感列表 -> 灵感详情 -> 收藏到一个合集 -> 合集列表 -> 合集详情
  - 后台用户列表 -> 查看菜谱域 -> 查看已发布 / 草稿 / 合集 -> 查看合集内容
- 失败 / 阻断路径：
  - 未登录访问我的、草稿、收藏写操作时触发登录
  - 分类、食材、单位不可用或越权时阻断
  - 版本冲突、重复提交、重复收藏时返回明确冲突语义
  - 对不存在或无权访问的菜谱、草稿、合集或合集内容返回明确错误
- 结束状态：
  - 新建或编辑后的菜谱以最新固定版本出现在“我的”
  - 收藏成功后合集和后台用户合集域可见真实内容
  - 后台可核对同一用户的概览与明细口径一致
- 确认人 / 确认记录：
  - 用户于 2026-07-26 确认：
    - 本轮包含合集真实内容
    - 前台编辑页允许更结构化的当前项目风格录入
    - 后台用户菜谱域采用“用户页入口 + 独立详情页”

### 页面行为

- 页面入口：
  - 小程序：`pages/recipe/index`、`pages_recipe/edit/index`、`pages_recipe/list/index`、`pages_recipe/detail/index`
  - 后台：`UsersPage` 进入独立用户菜谱域详情页
- 展示内容及用途：
  - 我的：已发布菜谱摘要、分类筛选
  - 草稿箱：草稿摘要和继续编辑入口
  - 菜谱详情：完整正文快照
  - 灵感：只读摘要与详情
  - 合集：合集摘要、合集内菜谱列表
  - 后台：用户菜谱域概览、已发布列表、草稿列表、合集列表、合集内容
- 用户操作：
  - 录入结构化字段、保存草稿、发布、删除草稿、删除菜谱
  - 收藏灵感菜谱到合集
  - 后台查看用户菜谱域明细
- 加载 / 空态 / 失败态：
  - 创建页、列表页、详情页、后台页均需具备加载、空态、失败态和重试
  - 未登录下“我的”、草稿和收藏写操作需触发登录
- 成功后的页面变化：
  - 发布后跳转我的详情
  - 收藏后合集列表和合集详情立即可见
  - 后台进入用户菜谱域后能看到最新数据
- 本流程不需要的页面数据：
  - 推荐审核状态
  - 点赞/收藏排行榜
  - 图片上传临时区信息

### 已冻结实现规则

1. `RecipeScene` 继续表示“个人场景 / 合集容器”，但本轮合集真实内容不得直接用现有 `RecipeSceneLink` 冒充收藏主事实。
2. 本轮新增“收藏关系”最小主事实，用来表达“某用户持有某个灵感固定版本”；场景只是收藏归属维度，不产生重复收藏条数。
3. 小程序合集列表继续留在 `pages/recipe/index` 的 `合集` Tab；点击合集内容后，复用统一 `pages_recipe/detail/index` 菜谱详情页，不再新增第二套小程序详情模板。
4. 后台采用“用户列表入口 + 独立用户菜谱域详情页 + 3 个 tab（已发布 / 草稿 / 合集） + 某用户某合集内容页”结构，不把菜谱域继续塞进现有权益抽屉。
5. 后台用户菜谱域先冻结为只读审计面；本轮不允许后台直接编辑、发布、删除、移出合集或改场景。
6. 本轮默认支持 `recipe.md` 已确认的多场景归属规则：同一固定版本只允许一条收藏主记录，可关联 `0-N` 个个人场景。
7. 合集详情与后台合集内容页都以“收藏的固定版本快照”为展示对象；来源菜谱后续更新不得自动改写已收藏内容。
8. 本轮步骤展示和录入只承诺文本步骤；不开放图片步骤录入或图片步骤展示。
