```text
业务流程 -> 页面行为 -> 权限和状态 -> 最小接口 -> 最小数据表/约束 -> 实现 -> 真实验收
```

## 执行规则

1. 开发进入上述功能时，先从本表复制问题到对应功能执行单。
2. 未完成业务流程和页面行为确认，不修改接口、表、索引或 migration。
3. 确认后的结论写入领域主文档和 API 契约，本表只更新状态并链接功能执行单。
4. 并发唯一性必须由数据库约束、锁或等价机制保证，不能只依赖“先查后写”。
5. 完成以真实端到端验收为准，不以代码、OpenAPI 或表已经存在为准。
