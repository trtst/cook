# 功能执行单：本周灵感专题页

## 目标

- 本功能要跑通的最小业务闭环：
  - 运营在后台维护“本周灵感”专题的基础信息、封面图和本期推荐菜谱。
  - 小程序首页首屏右上卡可以跳到“本周灵感”专题页。
  - 用户在专题页查看本期推荐菜谱和往期推荐，并可从专题页顶部 CTA 选择一道菜带到现有“下一餐计划”页。
- 对应 V1 范围：
  - 属于首页运营与灵感菜谱曝光编排，不新增社区、评论、打卡、关注、排行榜或专题收藏体系。

## 本轮范围

- 小程序端：
  - 新增“本周灵感”专题页。
  - 首页入口支持跳转专题页。
  - 专题页顶部 CTA 通过选菜面板跳到现有“下一餐计划”页。
- 后端 API：
  - 新增本周灵感专题公开读取接口。
  - 新增后台专题维护接口。
  - 首页快捷入口白名单补专题页路径，默认“本周灵感”入口改用专题页。
- 后台管理：
  - 新增“运营 / 本周灵感”配置页。
  - 支持维护专题基础信息、封面图和本期推荐菜谱顺序。
- 共享契约：
  - 新增专题页公开响应、后台响应和写入 DTO。

## 本轮不做

- 不做评论、打卡、精华区、话题主持人、参与人数和任何社区互动流。
- 不做“收藏专题”以及“我的收藏专题”入口。
- 不做专题级一键写入计划，也不新增计划批量写接口。
- 不做节庆专题页；节庆仍保持独立运营线。
- 不做专题推荐统计、专题点赞或专题分享回流。

## 业务流程与页面行为门禁

### 业务流程

- 用户目标：
  - 在首页点进“本周灵感”后，快速看到本期运营推荐的几道菜，并把其中一道带去安排下一餐。
- 触发条件：
  - 首页首屏右上卡配置为“本周灵感”专题入口。
  - 或用户在专题页里点击往期推荐卡片。
- 主成功路径：
  - 进入专题页 -> 查看专题头图、类别、描述、本期推荐菜谱 -> 点击顶部“加入我的计划” -> 在上滑面板里选一道菜 -> 跳转现有 `pages_meal/plan/index?recipeId=...`。
- 失败 / 阻断路径：
  - 当前没有任何已发布专题时，专题页展示空态。
  - 指定 `topicId` 不存在时，专题页展示失败态并可返回。
  - 专题存在但某道推荐菜谱已不可曝光时，该菜从专题列表中自动过滤，不阻断整个专题读取。
- 结束状态：
  - 用户停留在专题页继续浏览，或带着所选 `recipeId` 进入现有计划页。
- 确认人 / 确认记录：
  - 当前对话已确认：专题页参考社区编排感，但不做社区能力；“本周灵感”不是泛灵感列表，而是独立运营专题页。

### 页面行为

- 页面入口：
  - 首页首屏右上卡。
  - 专题页内部“往期推荐”横滑卡片。
- 展示内容及用途：
  - 头图区：模糊背景、封面、专题名、推荐类别、期次/更新时间、一句描述。
  - 本期推荐：展示专题当前配置的全部推荐菜谱，至少 `3` 道。
  - 往期推荐：横向滑动卡片。
- 用户操作：
  - 点击专题头部 CTA，打开选菜上滑面板。
  - 点击某道菜，进入菜谱详情。
  - 在 CTA 上滑面板中选某道菜，跳到现有计划页。
  - 点击往期卡片，切换到对应专题。
- 加载 / 空态 / 失败态：
  - 首屏 skeleton。
  - 无专题空态。
  - 指定专题不存在或读取失败时显示失败态。
- 成功后的页面变化：
  - 读取成功后显示专题详情。
  - 从 CTA 面板选菜后跳到现有计划页。
- 本流程不需要的页面数据：
  - 评论、打卡、话题标签、作者信息、关注关系、专题收藏关系、专题互动计数。

  - 不涉及。

  - 否。

## 最小数据表与约束

| 主事实 / 关系 | owner | 必要字段 | 生命周期 | 外键 / 唯一 / Check | 对应真实查询 | 是否复用现有结构 |
| --- | --- | --- | --- | --- | --- | --- |
| `HomeTopic` | `PLATFORM` | 标题、副标题、推荐类别、状态、期次、描述、封面图、版本、发布时间 | 新建、更新、上/下架、长期保留为往期 | `issueNo` 唯一；期次非负；版本正数 | 当前专题、按 `topicId` 读专题、按时间列往期 | 否 |
| `HomeTopicItem` | `PLATFORM` | `topicId`、`recipeId`、排序 | 新建、重排、删除 | `(topicId, recipeId)` 唯一；`topicId + sortOrder` 唯一；`recipeId` 外键到 `Recipe` | 读取专题内推荐菜谱顺序 | 否 |

- 可以从现有主事实重算、不新增持久化的内容：
  - 菜谱标题、封面、分类、点赞数、收藏数、难度、时长。
- 明确不新增的表、字段、枚举和索引：
  - 不新增专题收藏、专题点赞、专题评论和专题打卡表。
- migration 部署与回退边界：
  - 本地开发阶段按新 migration 直接前进，不保留旧占位契约 fallback。

## 风险与遗留

- 风险：
  - 当前头部 CTA 不直接写计划，而是选菜后跳现有计划页；若后续要求“一键加入本期”，需单独确认计划批量写合同。
  - 当前只支持 `LISTED / UNLISTED` 两态，不支持草稿态和定时发布。
- 遗留：
  - 节庆专题页独立执行。
  - 若后续需要专题标签、专题分享或专题排序策略，单独开执行单。
