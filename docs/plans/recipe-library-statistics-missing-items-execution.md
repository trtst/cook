# 菜谱库统计缺失项直达

## 已确认范围

- 目标：在 Admin 菜谱库统计中，从缺失数量直达缺标签菜谱并快速编辑。
- 统计来源：公开灵感菜谱当前 ACTIVE 版本。
- 快照：保留缓存统计；页面显示快照生成时间。
- 缺失清单：点击缺失数时按当前数据库实时筛选，分页返回；编辑后快照数值需手动重建。
- 页面：分类覆盖和分类分布合并为“分类数据”卡片；覆盖矩阵保留全部维度，选中维度显示分布明细。
- 权限：沿用菜谱库统计，仅 SUPER_ADMIN。

## 页面行为

1. 查看快照中的各维度菜谱数、缺失数和覆盖率；核心类别食材单独列出含有数、无需数、缺失数和覆盖率。
2. 点击维度行切换下方分类占比明细。
3. 点击有缺失的维度打开侧边栏，实时查询当前缺失菜谱；“待核对”中的 OTHER 分类项可查看对应菜谱。核心类别食材的无需数不进入缺失清单。
4. 点击营养分析覆盖或营养状态卡，查看对应营养状态的菜谱。
5. 从菜谱行进入现有系统菜谱编辑页。
6. 返回统计页后可手动重建快照，确认覆盖率变化。

## 接口契约

| 方法 | 路径 | 用途 | 权限 |
| --- | --- | --- | --- |
| GET | `/admin/home-topics/statistics/missing-recipes` | 按维度实时分页读取当前缺标签的公开菜谱 | SUPER_ADMIN |

参数：`dimension + page + pageSize`；可选 `value` 精确筛选该维度下的分类值，普通维度省略时查询缺失项；`nutrition` 维度支持状态值和 `HAS_ANALYSIS`。响应：`items(id, title, coverImageUrl) + page + pageSize + total + hasNext + checkedAt`。最大 `pageSize=100`。不新增数据库表、字段或 migration。

## 明确不做

- 不将缺失菜谱 ID 写入统计快照。
- 不自动重建快照。
- 不新增菜谱字段、数据表或 migration。
- 不做批量编辑或自动补标签。

## 风险与口径

- 缺失清单是当前数据，快照数字是最近重建时的数据；编辑后需手动重建快照。
- 核心类别食材分布统计分类 ID `5001–5004`，并按系统食材身份排除葱类（含小葱、大葱及葱花、葱段、葱末等形态，不含洋葱）、姜类（含姜片等形态）、蒜类（含大蒜、蒜末、蒜片等形态）和小米辣；无需剩余核心类别食材的菜谱进入 `notApplicableCount`，不作为缺失。主要食材标签不限制分类，但标签必须关联当前菜谱食材 JSON 中的 ACTIVE 系统食材，并且按已确认标签判断。
