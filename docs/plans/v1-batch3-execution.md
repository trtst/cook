# 炊火记 V1 第三批执行单

## 目标

第三批只补辅助层，不反向阻塞 P0 主闭环上线。

本批只做：

1. 营养展示
2. 菜品知识底座

## 一、已冻结边界

### 营养展示

- 只上菜谱详情页
- 只读展示：
  - 热量
  - 蛋白质
  - 脂肪
  - 碳水
- 第一版以后台人工维护为主
- 不做自动计算闭环
- 数据不足时按降级文案展示

### 菜品知识底座

- 只做后端能力
- 第一版最小范围：
  - 别名归一
  - 同菜归一
  - 搜索承接
- 不做前台独立 Wiki 页
- 不做百科社区
- 不做复杂知识图谱
- 不要求支撑 V1 点菜池的概念归一

## 二、本批要做什么

### 模块 6：营养展示

- 菜谱详情页展示四项营养信息
- 数据不足时展示三档降级文案

### 模块 7：菜品知识底座

- 搜索可命中别名
- 后端具备最小同菜归一能力
- 菜谱页内可承接概念聚合结果

## 三、如何验证

### 营养展示

- 菜谱详情页有数据时能显示四项营养
- 数据不足时正确显示三档文案：
  - `估算较完整`
  - `结果为估算`
  - `当前数据不足`
- 列表页和计划页不出现营养展示

### 菜品知识底座

- 用别名搜索可找到目标菜谱或食材
- 相近同菜可聚合到同一概念结果
- 聚合结果继续在菜谱页内承接，不新起独立搜索页

## 四、本批不做

- 营养推荐
- 减脂方案
- AI 营养师
- 自动营养识别
- 点菜池概念归一
- 知识图谱
- 关联推荐

## 五、执行原则

- 第三批失败不反向阻塞 P0 上线
- 第三批可以降级，不可以扩范围
- 所有前台展示都必须服从“辅助层”定位，不得重新抢占主流程

## 六、一句话结论

第三批只补：

**详情页营养信息 + 后端搜索基础能力**

不重新打开新的主流程。
