# 功能执行单：食材筛选导出与图片批量上传

## 目标

- 系统食材页按当前筛选结果导出 `id:name` JSON。
- 系统食材图片支持按本地文件名中的食材 ID 批量上传，并把生成 URL 保存到 `Ingredient.imageUrl`。
- 现有单张上传同步写入 `imageUrl`。
- 对应 V1 范围：后台系统食材治理。

## 本轮范围

- 当前阶段：食材图片处理、缺图筛选、按当前筛选全量 JSON 导出、按文件名 ID 批量上传回填 `imageUrl`、页面内批量文本导入移除均已实现。
- 后续阶段：菜谱图片复用仍单独规划。
- 小程序端：本阶段只将食材摘要改为读取持久化 `imageUrl`。
- 共享契约：API DTO、OpenAPI、API 契约、后台类型与 Prisma migration 同步。

## 本轮不做

- 菜谱批量图片上传与 URL 回写。
- 独立食材 JSON 导入流程。
- 旧图片 URL 回填、兼容和 fallback。
- ZIP/远程 URL 导入和通用媒体管理。

## 业务流程与页面行为门禁

### 业务流程

- 用户目标：导出目标系统食材身份清单，并为食材批量上传图片。
- 触发条件：超级管理员在系统食材页选择筛选条件或本地图片。
- 主成功路径：按状态/分类/关键词/结构化属性/图片地址筛选 -> 导出完整匹配 JSON；或选择图片 -> 从文件名解析 ID -> 上传 -> 保存生成 URL -> 刷新列表。
- 失败/阻断路径：无导出结果、文件名不合法/重复、ID 不存在、格式/规格不符、版本冲突、存储错误；逐项报告，批量允许部分成功。
- 结束状态：导出文件已下载；或页面汇总成功和失败项并反映最新图片地址。
- 确认人/记录：用户在本会话确认。

### 页面行为

- 页面入口：后台“系统食材”页 header；独立“食材导入”菜单保留。
- 展示内容及用途：沿用现有状态、分类、关键词与结构化属性筛选；增加“没有图片地址”筛选。
- 用户操作：header 批量导出；选本地图片批量上传；现有行内编辑单张上传继续可用。
- 加载/空态/失败态：批量过程显示进度和逐项结果；无筛选结果不下载文件；筛选状态保持。
- 成功后的页面变化：下载 `id:name` JSON；上传后刷新列表；启用“没有图片地址”时，补图成功的食材离开当前结果集。
- 本流程不需要的页面数据：不返回营养详情或完整食材对象给导出，仅导出 ID 与名称。

| POST | `/admin/ingredients/{ingredientId}/image` | 单张图片上传并持久化 imageUrl；批量 UI 逐项复用 | SUPER_ADMIN | `Idempotency-Key` | expectedVersion | 图片阶段已实现 |

## 最小数据变更

| 主事实 | owner | 必要字段 | 生命周期 | 对应查询 | 状态 |
| --- | --- | --- | --- | --- | --- |
| 系统食材图片公开地址 | Ingredient | `imageUrl: string | null` | 上传替换时更新；清空时置 null | 各食材摘要图片展示及缺图筛选 | 已实现 |

- 旧记录不回填，旧地址不作 fallback。
- 不新增图片子表、批量任务表或预留菜谱字段。
- 单张上传：原图不超过 2 MB、边长不超过 1125 像素，浏览器 Canvas 编码为 JPG quality 0.8。
- 批量上传：每张原图不超过 2 MB、边长不超过 1125 像素，张数不限制，浏览器 Canvas 编码为 JPG quality 1。
- 两种上传都要求严格 1:1；任一边小于 300 像素拒绝；300 至 500 像素保持原尺寸；超过 500×500 等比例缩至 500×500。
- 批次不限制文件数，逐张串行处理；结果每页显示 50 项。食材 ID 查找逐页扫描但只保留本批目标 ID 的摘要，避免缓存完整食材集合。
- 批量图片使用浏览器 Canvas 编码为 JPG quality 1；单张上传 quality 仍为 0.8。`imageUrl` 附带 OSS 参数使读取结果固定为 300×300。
- `imageUpdatedAt` 仅作为上传时间/版本信息，不用于旧图 URL fallback。
- 无 `ASSET_PUBLIC_BASE_URL` 时数据库保存 API 相对路径；接收 RequestLike 的响应按当前请求 Host 展开，不把临时请求 Host 落库。

## 各端类型

- `apps/api`：Ingredient model、Admin DTO、公开食材摘要及上传响应。
- `apps/client`：仅当共享公开食材类型受影响时同步 `imageUrl` 语义。
- `apps/admin`：列表筛选、批量上传与导出类型。

## 风险与遗留

- 图片读取已改为 `imageUrl` 唯一事实；旧记录保持 `null`，不会从 `imageUpdatedAt + object key` 推导。
- OSS 的 `300×300` URL 变换需部署环境配置公开静态域名并通过 OSS/CDN 提供；API 代理路径不执行 OSS query 变换。
- 真实 OSS/CDN 和后台浏览器验收仍需独立执行。
