# 功能执行单：后台运营治理重构

## 目标

- 把当前后台从“单页运营工具集合”升级为 3 条清晰治理线：`运营看板`、`会员治理`、`内容治理`。
- 先跑通最小后台业务闭环：会员兑换码治理拆分、内容文章发布与官网固定页维护、首页核心指标摘要与趋势查看。
- 对应 V1 范围：后台治理、会员兑换码运营、官网与纯展示内容维护、基础审核/举报待办；不扩成通用 CMS、社区后台或复杂 BI 平台。

## 当前确认

- 会员兑换码后台要从现有单页拆成类似“菜谱治理”的多子页结构。
- 需要新增后台富文本编辑器，用于维护官网固定内容与后台发布文章。
- 后台文章首批至少覆盖：`关于我们`、`隐私政策`、`用户协议`、`产品介绍`、`FAQ`、`餐前准备`、`厨房知识`。
- 后台首页除了当前摘要卡，还需要展示核心数据趋势图。
- 编辑器优先参考外部 chat 项目里的 Quill 方案，但只能按炊火记后台需要做裁剪集成，不能整套照搬其聊天或项目私有逻辑。

### 业务流程

- 用户目标：
  - 运营同学能拆分管理会员 SKU、批次、生成记录、核销记录。
  - 内容同学能维护官网固定页，并发布“餐前准备 / 厨房知识”等文章。
  - 管理员打开后台首页就能看到核心待办与趋势。
- 触发条件：
  - 进入后台首页。
  - 点击“会员治理”菜单。
  - 点击“内容治理”菜单。
- 主成功路径：
  - 管理员登录后台后，先在看板查看待办和趋势，再进入会员治理或内容治理完成具体操作。
  - 会员治理支持 `查看 SKU -> 建批次 -> 生码 -> 查看生成记录 -> 查看核销记录`。
  - 内容治理支持 `选择栏目/固定页 -> 编辑正文 -> 预览 -> 上下架/发布`。
- 失败 / 阻断路径：
  - 无权限用户不可进入这些页面。
  - 会员治理的并发写入继续用 `Idempotency-Key`、`version / expectedVersion` 和审计防重。
  - 内容正文保存失败、发布失败、图片上传失败要分开提示，不合并成“保存失败”一类模糊口径。
- 结束状态：
  - 后台 IA、页面 owner、接口 owner、数据 owner 和实施顺序冻结。
- 确认人 / 确认记录：
  - 本轮对话已确认：先做后台重构方案，会员治理拆分、编辑器、内容发布和 Dashboard 趋势都纳入同一执行单。

### 页面行为

- 页面入口：
  - `首页 / 运营看板`
  - `会员治理 / SKU 管理`
  - `会员治理 / 兑换码批次`
  - `会员治理 / 创建记录`
  - `会员治理 / 兑换码列表`
  - `会员治理 / 核销记录`
  - `内容治理 / 固定页`
  - `内容治理 / 文章列表`
  - `内容治理 / 栏目管理`
  - `内容治理 / 新建文章`
- 展示内容及用途：
  - 看板：摘要卡、待办卡、趋势图、快捷入口。
  - 会员治理：分离“配置、批次、生成、核销”四种不同任务，不再混在一个页面滚动区里。
  - 内容治理：把“官网固定页”和“栏目文章”统一到同一内容主事实，但入口与过滤器分开，避免运营误操作。
- 用户操作：
  - 看板支持按卡片和趋势区域跳转。
  - 会员治理支持创建批次、上/下架、生成兑换码、停用未使用兑换码、查询生成与核销记录。
  - 内容治理支持新建、编辑、保存草稿、预览、发布、下架。
- 加载 / 空态 / 失败态：
  - 看板趋势为空时显示“暂无趋势数据”，不渲染假折线。
  - 固定页页签固定展示默认种子页，运营直接进入编辑，不走“先出现空态、再单独创建固定页”的初始化流程。
  - 核销记录为空时展示“暂无核销记录”，不与“兑换码列表为空”共用文案。
- 成功后的页面变化：
  - 批次、状态、内容发布成功后，只刷新当前列表和相关摘要，不要求整页 reload。
  - 固定页发布成功后，列表展示最新 `updatedAt / publishedAt / operator`。
- 本流程不需要的页面数据：
  - 看板不返回分页明细。
  - 文章编辑页不返回全站统计。
  - 会员 SKU 管理不返回单码详情分页。

## 内容治理方案

### 方案结论

- “官网固定页”和“餐前准备/厨房知识文章”不要做两套后台。
- 两者共用同一内容主事实，只通过 `contentType / channel / slug / visibility` 区分。
- 内容治理优先服务 `apps/site` 和小程序 `web-view`，不在 `apps/client` 里再维护第二套正文结构。

### 首版内容分类

| 分类 | 用途 | 典型 slug |
| --- | --- | --- |
| 固定页 | 官网和法务固定承接 | `about`、`privacy`、`terms`、`product`、`faq` |
| 文章 | 可持续发布的内容 | `/guides/{slug}`，首批承接餐前准备与厨房知识 |

### 最小字段建议
