# 功能执行单：会员兑换码与权益页

## 目标

- 本功能要跑通的最小业务闭环：用户从“我的”页进入权益中心或会员兑换码页，查看当前会员档位与已确认权益规则，并完成真实兑换码核销；后台可创建批次、批量生成兑换码、导出一次性明文、查询状态和停用风险码。
- 对应 V1 范围：个人会员权益展示、站外购买后的站内核销入口、广告减免规则确认；不进入站内支付。

## 本轮范围

- 小程序端：
  - “我的”页会员角标点击进入权益中心。
  - “我的”页在现有“个人服务”上方新增“权益服务 / 会员服务”两个独立入口。
  - 新增 `权益中心` 页面与 `会员兑换码` 页面。
- 后端 API：
  - 已实现 `POST /membership-codes/redeem`，核销成功后写入当前用户有效会员事实。
  - 已实现后台 `SKU / 批次 / 生码 / 列表 / 停用` 最小接口。
- 后台管理：
  - 已实现“会员兑换码”页面，支持固定 SKU 查看、批次创建、批量生码、一次性导出、状态查询与停用。
- 共享契约：
  - 先冻结正式会员码、体验码与广告减免边界，不引入支付契约。

## 本轮不做

- 小程序内下单、订单、支付回调、自动续费。
- 助手 / 识图次数账本与激励广告真实发放链路。

## 业务流程与页面行为门禁

### 业务流程

- 用户目标：
  - 查看当前会员权益。
  - 进入会员兑换码页，了解当前兑换规则并为后续真实核销留入口。
- 触发条件：
  - 点击“我的”页昵称旁会员角标。
  - 点击“权益服务”中的“权益中心”。
  - 点击“会员服务”中的“会员兑换码”。
- 主成功路径：
  - 已登录用户进入目标页，查看当前会员档位、有效期、当前已冻结的权益与广告规则。
- 失败 / 阻断路径：
  - 未登录时先打开登录弹窗。
  - 兑换码无效、已停用、未上架、超体验上限、重复使用等失败口径统一返回“兑换码无效或不可用”。
- 结束状态：
  - 用户可稳定到达权益中心和会员兑换码页。
  - 规则文档完成冻结，后续核销能力按本文与 `configuration.md` 接入。
- 确认人 / 确认记录：
  - 本轮对话已确认：正式会员先开放 `PLUS_30D / PRO_30D`；季卡/年卡可预建但默认不可核销；体验码只允许 `1 / 3 / 7` 天且累计不超过 `7` 天。

### 页面行为

- 页面入口：
  - `pages/me/index` 会员角标。
  - `pages/me/index` 新增“权益服务 / 会员服务”区块。
- 展示内容及用途：
  - 权益中心：当前档位、有效期、正式会员权益对照、广告减免说明、次数型能力边界说明。
  - 会员兑换码：输入框、提交按钮、已冻结的兑换规则说明。
- 用户操作：
  - 点击权益中心入口查看说明。
  - 点击会员兑换码入口进入输入页。
  - 输入兑换码并点击确认；本轮只做校验和提示。
- 加载 / 空态 / 失败态：
  - 未登录展示既有登录引导。
  - 已登录直接使用当前 `userStore.profile.membership`，不新拉其他权益快照。
- 成功后的页面变化：
  - 小程序核销成功后立即刷新 `users/me`，当前账号会员状态同步到账。
- 本流程不需要的页面数据：
  - 不展示未实现的支付入口。
  - 不展示次数余额、广告剩余次数、历史核销记录等当前无真实事实的数据。

## 最小数据表与约束

当前已实现核销最小主事实：

| 主事实 / 关系 | owner | 必要字段 | 生命周期 | 外键 / 唯一 / Check | 对应真实查询 | 是否复用现有结构 |
| --- | --- | --- | --- | --- | --- | --- |
| 会员 SKU | USER 会员策略 | `code / kind / tier / durationDays / redeemEnabled` | 长期配置 | `UNIQUE(code)`、`CHECK(kind+durationDays)` | 判断档位和时长是否合法 | 新增 `membership_skus` |
| 兑换码批次 | USER 会员策略 | `skuId / name / redeemEnabled / startsAt / endsAt / version` | 可启停 | `FK(skuId)`、时间窗 Check、`version` 并发保护 | 判断当前批次是否开放 | 新增 `membership_code_batches` |
| 单码事实 | USER 核销凭证 | `batchId / codeHash / codeMask / status / redeemedBy / redeemedAt` | 一次性 | `UNIQUE(codeHash)`、已核销状态 Check | 精确查码核销和累计体验查询 | 新增 `membership_codes` |
| 有效会员事实 | USER | `tier / startsAt / endsAt` | 已存在 | 当前现有约束 | 运行时解析权益 | 复用 `EntitlementGrant` |

- 明确不新增的表、字段、枚举和索引：
  - 不新增支付订单与自动续费结构。
- migration 部署与回退边界：
  - 新增 `20260818170000_membership_code_redeem`。
