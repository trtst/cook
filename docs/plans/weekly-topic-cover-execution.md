# 功能执行单：共享周刊 4:3 封面上传与生成

## 目标

- 本功能最小业务闭环：管理员编辑已保存的共享周刊，可上传封面或点击「生成封面图」生成并保存封面；小程序码扫描后进入同一期周刊。
- 对应 V1 范围：共享周刊后台管理与小程序展示。

## 本轮范围

- 小程序端：当前期封面 4:3 展示；支持小程序码 `scene` 打开指定周刊。
- 后端 API：周刊封面上传改为居中裁切 `4:3`；提供指定周刊小程序码 Data URL。
- 后台管理：封面比例改为 `4:3`；上传控件旁添加封面生成按钮，生成后沿用现有上传接口保存。
- 共享契约：更新 Admin API、OpenAPI 和本地类型。

## 本轮不做

- 不批量重制历史封面；既有图片对象不重裁。
- 不新增封面字段、封面历史表或二维码持久化记录。
- 不改造饭局回忆卡，不增加封面模板编辑器或自定义文案能力。

## 业务流程与页面行为门禁

### 业务流程

- 用户目标：为每期共享周刊提供比例一致、包含周期和入口码的封面。
- 触发条件：管理员打开已保存的周刊；生成时本期标题和周期已填写。
- 主成功路径：管理员点击「生成封面图」；后台获取该期小程序码，在 `1200 × 900` Canvas 上合成封面并上传；现有封面仅在上传成功后替换，周刊版本递增。
- 失败 / 阻断路径：周刊未保存、标题/周期缺失、字体/背景/小程序码加载失败、图片导出失败或版本冲突时不替换现有封面并提示原因。
- 结束状态：周刊 `coverImageUrl` 指向生成或手动上传的 4:3 图片；二维码打开对应 `topicId`。
- 确认人 / 确认记录：用户于 2026-10-13 确认 4:3、周期日期位置、底部文案、生成入口和动态标题；标题使用当期标题，不是固定标题。

### 页面行为

- 页面入口：后台共享周刊编辑页；小程序周刊详情页与往期列表。
- 展示内容及用途：生成封面使用背景 `https://static.trtst.com/O/uploads/home-topics/weekly-topic.jpg`、标题字体 `CHJ-Kai`（`chuihuoji_han.ttf`）、正文 `SC-Medium` 字体、当期标题、本期周期、当前系统 slogan、固定底部文案和该期小程序码。底部固定为「家的味道，都在这里了」与「长按识别小程序码 · 一起看看这周吃什么」，两行使用相同字体、字重和字号，并与小程序码垂直居中。日期位于花椒右侧留白处居中；二维码背景透明、码点显示为白色并放大，中心叠加裁去透明边距的 `apps/client/src/assets/logo.png`。
- 用户操作：管理员可点击封面图上传，也可点击相邻的「生成封面图」；两者均替换当前封面。
- 加载 / 空态 / 失败态：生成按钮显示忙碌状态并防止重复操作；缺少已保存资源、标题或周期时不调用生成流程；图片或 API 失败时保留当前封面。
- 成功后的页面变化：更新封面预览及版本号；客户端当前期、历史期和分享图片读取同一封面 URL。
- 本流程不需要的页面数据：饭局参与人、菜单快照、回忆文案、饭局分享 token。

## 开发者最小任务确认

### 小程序确认

- 最小交付：显示周刊封面的页面统一按 `4:3`；扫描该期二维码时从 `scene` 读取周刊 ID。
- 依赖：服务端生成的 `pages_home/topic/index` 周刊码。
- 是否先用 mock：否。
- 不做项：不改菜谱卡片比例和饭局回忆卡。
- 验收方式：客户端类型检查及路由参数静态检查。

### 后端确认

- 最小交付：上传压缩器居中裁切 `4:3`；通过 `GET /admin/home-topics/{topicId}/mini-code` 返回指定周刊码 Data URL。
- 数据表 / 事务边界：不增加数据库写入；封面最终写入继续使用现有带 `expectedVersion` 和 `Idempotency-Key` 的上传接口。
- 错误码：沿用统一 API envelope 和现有微信小程序码错误处理。
- 不做项：不持久化单独的码文件，不新增迁移。
- 验收方式：API 类型检查和 OpenAPI 验证；微信真实码需在发布前接受扫码验证。
- 状态机 / 权限矩阵：mini-code 读取沿用 Admin Bearer；封面替换沿用现有图片上传权限与版本冲突保护。
- 配置解析与实例冻结：复用 `WECHAT_MINI_CODE_ENV_VERSION`、`WECHAT_APP_ID`、`WECHAT_APP_SECRET`。
- 到期 / 清理任务：无。

### 后台确认

- 最小交付：周刊封面旁增加「生成封面图」，使用当期标题和周期合成 4:3 JPEG，调用现有上传接口保存。
- 页面入口 / 权限：周刊编辑页；沿用后台登录态及现有封面上传权限。
- 依赖：周刊码 Data URL 和静态背景/字体资源。
- 不做项：不增加人工编辑坐标、文案或颜色的能力。
- 验收方式：后台类型检查；需在浏览器核对 CORS 字体/背景和生成后封面预览。

## 风险与遗留

- 风险：后台 Canvas 导出要求静态背景图和字体服务器允许跨域读取；浏览器联调需核对。
- 遗留：当前自动生成依赖周刊先保存；未保存的新建草稿不能生成封面。
- 发布前必须处理：真实 Admin 环境生成图片并扫码确认二维码打开本期周刊。
