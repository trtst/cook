# 功能执行单：全局登录弹窗、测试验证码登录与登录图配置

## 目标

- 本功能要跑通的最小业务闭环：客户端任意登录入口呼起全局最高层登录弹窗；小程序初始态展示图片、App 名称、slogan、微信快捷登录按钮和手机号验证码登录按钮；非小程序直接显示手机号验证码表单；输入合法手机号与测试验证码 `123456` 后完成登录，自动注册新手机号；客户端启动读取公共 `app-config`，后台可上传、替换和清空登录弹窗图片。
- 对应 V1 范围：账号基础链路、公开启动配置、后台配置维护。未扩到真实短信、微信手机号授权、通用配置中心或通用素材库。

## 本轮范围

- 小程序端：`App.vue` 全局登录弹窗宿主、登录 CTA 组件、测试验证码登录、启动 `app-config` 读取、H5/小程序分支、`我的` 页面局部登录弹窗收口。
- 后端 API：新增 `POST /auth/code-login`、`GET /app-config`、`GET/POST/DELETE /admin/app-config/*`、受控登录图读取 URL，本地文件资产槽位。
- 后台管理：新增“公共配置”页，支持上传 / 预览 / 替换 / 清空登录图。
- 共享契约：同步 `docs/api-contract.md`、三端本地类型与请求。

## 本轮不做

- 不接真实短信发送、验证码表、短信供应商和验证码核销中心。
- 不接微信手机号快捷登录真实链路；按钮只保留，不触发行为。
- 不下线旧密码登录、不改密码修改契约。
- 不扩成通用配置中心、通用素材库、图片裁剪或节日排期系统。

## 业务流程与页面行为门禁

### 业务流程

- 用户目标：在未登录时，通过全局登录弹窗进入账号体系，并在后续节日活动中可由后台替换登录图。
- 触发条件：页面内登录 CTA、`我的` 页需要登录的操作入口。
- 主成功路径：
  - 客户端打开全局登录弹窗。
  - 小程序显示初始态；非小程序直接显示手机号验证码表单。
  - 用户输入合法手机号和验证码 `123456`。
  - 服务端按手机号查找账号；没有则自动注册并生成 uid。
  - 服务端返回 token 和用户摘要；客户端写 session、读取 `/users/me`、刷新饭搭子上下文并关闭弹窗。
  - 后台上传登录图后，`GET /app-config` 返回新的公开图片 URL；下次打开弹窗时使用新图。
- 失败 / 阻断路径：
  - 验证码不是 `123456` 返回失败提示。
  - `app-config` 失败、为空或图片失效时回退本地图。
  - 图片上传类型或大小不合法时后台提示失败。
- 结束状态：用户获得有效登录态；后台配置登录图后客户端后续打开弹窗可读取。
- 确认人 / 确认记录：2026-07-24，当前会话中用户明确确认“微信按钮本轮无行为”“非小程序按 H5 可测试”“验证码测试态固定 123456”。

### 页面行为

- 页面入口：`App.vue` 全局宿主；现有 `Login` 组件变成 CTA；`我的` 页按钮操作统一走全局弹窗。
- 展示内容及用途：
  - 登录弹窗展示登录图、App 名 `炊火记`、slogan `炊烟晚，人归缓，烟火暖流年`、按钮和手机号验证码表单。
  - 小程序初始态保留微信快捷登录按钮，但本轮不触发动作。
  - 后台配置页只展示当前登录图预览和管理动作。
- 用户操作：
  - 小程序初始态点“手机号验证码登录”后内容上滑扩展。
  - 非小程序直接输入手机号、验证码、发送验证码、登录。
  - 后台可上传、替换、清空。
- 加载 / 空态 / 失败态：
  - 启动异步拉取 `app-config`，不阻塞弹窗打开。
  - 无图或清空时客户端用默认图，后台页面显示空态说明。
  - 登录失败显示表单错误；上传失败显示消息。
- 成功后的页面变化：
  - 登录成功关闭弹窗；从 CTA 打开的页收到成功回调后按原页面逻辑继续刷新。
  - 后台上传成功后当前页刷新预览。
- 本流程不需要的页面数据：
  - 不需要把会员、权限、饭搭子、背景图显示配置塞进 `app-config`。
