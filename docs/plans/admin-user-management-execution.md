# 功能执行单：后台用户管理

## 目标

- 跑通 `SUPER_ADMIN` 查询、新增、编辑、启用、禁用和重置用户密码的最小闭环。
- 对应 V1 范围：后台用户管理与必要审计。

## 本轮范围

- 小程序端：消费统一 `401`，不新增页面或接口。
- 后端 API：用户管理写接口、幂等、审计和用户会话失效。
- 后台管理：用户列表中的新增、编辑、状态和密码操作。
- 共享契约：同步 `docs/api-contract.md`、OpenAPI 及后台本地类型。

## 本轮不做

- 不物理删除用户。
- 不修改用户饭搭子、菜谱、冰箱、计划或购物数据。
- 不新增通用权限中心或 token 黑名单。

## 业务流程与页面行为门禁

### 业务流程

- 用户目标：超级管理员在后台完成最小用户账号管理。
- 触发条件：管理员已登录且实时角色包含 `SUPER_ADMIN`。
- 主成功路径：查询目标用户，执行新增、资料修改、启用、禁用或重置密码，并刷新列表。
- 失败 / 阻断路径：参数错误返回 `400`，用户不存在返回 `404`，手机号重复返回 `409`，非超级管理员返回 `403`。
- 结束状态：账号事实更新、重要操作有审计、重复请求不产生第二次副作用。
- 确认人 / 确认记录：2026-07-25，当前工作区用户管理范围；当前会话确认修复禁用、重置密码后的旧 token 失效及昵称清空问题。

### 页面行为

- 页面入口：后台用户列表。
- 展示内容及用途：UID、昵称、手机号、状态和时间，用于定位账号与判断可执行操作。
- 用户操作：新增、编辑昵称或手机号、启用、禁用、重置密码。
- 加载 / 空态 / 失败态：列表和权益查询保留独立加载及错误提示；写操作失败保留弹窗内容。
- 成功后的页面变化：关闭对应弹窗并重新读取列表。
- 本流程不需要的页面数据：用户私有业务数据、密码哈希、会话版本和内部审计详情。

## 最小数据表与约束

| 主事实 / 关系 | owner | 必要字段 | 生命周期 | 外键 / 唯一 / Check | 对应真实查询 | 是否复用现有结构 |
| --- | --- | --- | --- | --- | --- | --- |
| 用户账号 | USER | `status`、`passwordHash`、`sessionVersion` | 用户账号全周期 | 手机号唯一；会话版本非负 | 登录与每次用户鉴权 | 复用 `User` |
| 管理幂等 | PLATFORM | 操作者、操作类型、请求哈希、结果 | 按既有清理规则 | 管理员操作唯一约束 | 写接口重试 | 复用 `IdempotencyRecord` |
| 管理审计 | PLATFORM | 操作者、动作、对象、最小摘要 | 长期审计 | 管理员外键 Restrict | 安全追溯 | 复用 `AuditEvent` |

- 可以从现有主事实重算、不新增持久化的内容：是否可继续使用某个 token，由用户状态、会话版本和签名即时判断。
- 明确不新增的表、字段、枚举和索引：不新增 token 表、黑名单表、缓存或会话索引。
- migration 部署与回退边界：前向新增带默认值的非空整数列和非负 Check；回退会使部署后签发的版本化 token 无法继续按新 Guard 使用，代码与 migration 必须一起回退。

## 风险与遗留

- migration 上线后旧用户 token 因缺少版本字段统一失效，需要重新登录。
- 每次用户鉴权增加一次按主键读取，确保状态与会话版本实时生效。
- 真实流程脚本会创建测试用户，仅在明确的测试数据库运行。

## 范围自检

- 本次满足的用户确认规则：修复后台昵称清空；禁用、启用和重置密码后旧 token 立即失效。
- 每个文件为什么必须修改：Schema/migration 保存主事实，token/Guard 执行鉴权，AdminService 变更状态，脚本和文档固定验收。
- 明确没有顺手加入的功能：未处理饭局入口、远程图片或字体，未扩展后台数据管理范围。
- 因复用未被证明而没有提前增加的抽象：未增加会话中心、token 仓库或缓存层。
- 是否还能缩小改动而不破坏需求：不能；移除会话版本会导致重新启用后旧 token 恢复有效。
