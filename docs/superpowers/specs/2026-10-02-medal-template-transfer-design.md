# 勋章模板配置导入导出设计

## 背景与目标

Admin 已有勋章模板治理页，但没有跨环境导入导出。目标是将测试环境中选中的已上架勋章模板配置同步到线上。线上目前没有勋章模板配置。

同步包不包含勋章图片文件、图片 URL 或用户已获得的勋章事实。此次只同步模板配置，不增加勋章发放、撤销或奖励能力。

## 已确认范围

- 在勋章模板页勾选要导出的模板；仅 `LISTED` 模板可选。
- 列表按现有服务端分页展示；翻页后保留勾选，“本页全选”只作用于当前页。
- 导出文件用于测试环境到线上环境的首次配置同步。
- 导入前校验并展示新增、更新和冲突；管理员确认后才写入。
- 导入按模板 `code` 匹配。新编码新增；已存在的编码更新可同步的配置字段。
- 同编码但 `awardRule` 不同视为冲突，整批不写入。模板编码和发放规则具有业务语义，导入不得静默改变它们。
- 同步包未包含的线上模板保留，不执行删除。
- 更新已存在模板时保留线上图片字段；导入不会清空或替换线上图片。
- 写入采用数据库事务、管理员幂等键和审计记录。

## JSON 数据边界

同步包使用独立格式版本 `cook.medal-templates.v1`，带 `sourceEnvironment` 和 `exportedAt`。

每条模板数据包含：

- `code`、`awardRule`、`category`
- `name`、`description`、`condition`
- `status`（导出和导入均为 `LISTED`）
- `targetCount`、`sortOrder`、`isLimited`、`startAt`、`endAt`

不包含：环境数据库 ID、`version`、创建/更新时间、`imageUrl`、`earnedImageUrl`、`lockedImageUrl`、图片文件和用户获得记录。`iconKey` 由服务端按 `awardRule` 推导，不作为可导入字段。

线上导入仅接受来源环境为 `TEST` 的包；环境身份沿用 `SYSTEM_DATA_ENVIRONMENT` 配置。目标环境必须为 `ONLINE`。

## 页面行为

在现有勋章模板表格增加行选择框、当前页全选、选择数量提示、导出所选和选择 JSON 文件入口。非 `LISTED` 行不可选。

没有选中模板时，导出按钮不可用。导出请求只提交选中模板 ID；服务端再次检查其状态为 `LISTED`，并从数据库读取规范字段生成文件，避免信任客户端数据。

选文件后显示解析/校验状态和导入预览，至少呈现来源环境、包格式、记录数、新增数、更新数和冲突原因。存在冲突时禁止确认导入。成功后提示新增/更新数量并刷新模板列表；失败时不写入部分数据并显示错误。

导出不受列表筛选条件影响，只包含用户明确勾选的行。翻页后保留选择；修改关键字、状态或类别筛选时清空选择；当前页全选不改变其他页的选择。

## 服务端行为

- 新增勋章模板专用导出、预览和导入接口，不扩充通用系统基础数据同步包。系统数据同步存在首次 TEST→ONLINE 后切换反向同步的门禁，不能承载本次及后续勋章配置同步。
- 所有接口沿用现有勋章模板的 `SUPER_ADMIN` 权限边界。
- 导出接口只接受所选 ID 集合，要求非空且数量有硬上限；最终数量和上限在实现时沿用 API/数据库规则并结合现有数据规模确定。
- 服务端校验 JSON 结构、版本、源环境、每条状态、枚举、日期范围、唯一 `code`、记录上限和文件大小。
- 预览按 `code` 汇总新增/更新；发现重复 code、发放规则不一致或字段非法时返回冲突，不执行写入。
- 导入在一个事务中按 code 新增或更新，不更新图片字段；更新时版本递增。相同幂等键与相同请求返回首次结果。
- 导入操作写管理员审计记录，审计只记录包版本、来源/目标环境、模板数量及新增/更新结果，不记录图片内容。

## 不在范围内

- 导出或导入图片字节、图片 URL、图片存储对象。
- 同步草稿、未上架或已归档模板。
- 同步用户获得勋章记录。
- 清理目标环境中未出现在数据包里的模板。
- 通用系统数据同步策略或其它内容域的导入导出。

## 验收

1. 跨页勾选的多个已上架模板可一次导出；导出内容不含数据库 ID 和图片字段。
2. 草稿、未上架、已归档模板不可勾选，也不会出现在导出文件中。
3. 合法测试环境数据包在空的线上环境预览为新增，确认后完整创建模板并保持 `LISTED`。
4. 相同 code、相同发放规则的重复导入更新同步字段并保留线上图片。
5. 相同 code、不同发放规则或任一非法记录使整批拒绝且无部分写入。
6. 非 TEST 来源或非 ONLINE 目标环境不能导入。
7. 未登录或非 `SUPER_ADMIN` 管理员不能导出、预览或导入。
8. 静态检查覆盖 API/Admin 类型与构建；真实线上导入只在功能部署后按用户确认执行并单独记录结果。

- Admin：勋章 API 类型、勋章模板页选择/导出/导入预览交互。
